## 🚀 Projetos Open Source

Lista dos repositórios brasileiros e seguros estruturados conforme a sua integração com APIs.

| # | Projeto | Descrição | Repositório | Interação com APIs |
| --- | --- | --- | --- | --- |
| 01 | BrasilAPI | Centraliza e facilita o acesso a dados públicos do Brasil. | [🔗 Repositório](https://github.com/brasilapi/brasilapi) | Transforma serviços isolados (Correios, IBGE, FIPE) em uma única API REST de alta disponibilidade. |
| 02 | Rocket.Chat | Plataforma global de colaboração e chat com foco em privacidade. | [🔗 Repositório](https://github.com/RocketChat/Rocket.Chat) | Consome e fornece dezenas de APIs (GraphQL, REST, WebSockets) para integrar chatbots e sistemas de terceiros. |
| 03 | Minha Receita | Sistema para democratizar a base de dados oficial de CNPJs da Receita Federal. | [🔗 Repositório](https://github.com/cuducos/minha-receita) | Expõe e orquestra endpoints HTTP rápidos para buscas corporativas automatizadas. |
| 04 | Tsuru | Plataforma como Serviço (PaaS) robusta e extensível originada pela equipe da Globo.com. | [🔗 Repositório](https://github.com/tsuru/tsuru) | Controla e provisiona aplicações em background consumindo diretamente as APIs do Docker e Kubernetes. |
| 05 | ScanAPI | Ferramenta de testes de integração de endpoints baseada em arquivos de configuração simples. | [🔗 Repositório](https://github.com/scanapi/scanapi) | Dispara requisições contínuas contra APIs externas para validar lógicas de negócio e gerar documentação. |
| 06 | CresceBR B2B | Plataforma escalável de marketplace voltada para operações corporativas. | [🔗 Repositório](https://www.google.com/search?q=https://github.com/oguarni/crescebr-b2b-marketplace) | Consome ativamente a BrasilAPI nos bastidores para realizar a validação rigorosa de CNPJs no momento do cadastro. |
| 07 | KubePug | Verificador de compatibilidade pré-atualização para infraestruturas baseadas em contêineres. | [🔗 Repositório](https://github.com/kubepug/kubepug) | Consulta constantemente as APIs nativas do Kubernetes para detectar objetos e recursos que ficarão obsoletos. |
| 08 | Fklearn | Biblioteca funcional de Machine Learning criada pela engenharia do Nubank. | [🔗 Repositório](https://github.com/nubank/fklearn) | Estruturada especificamente para que os modelos treinados sejam servidos e consumidos através de microsserviços e APIs. |
| 09 | BotCity | Framework Python para construção de robôs (RPA) de automação de processos em larga escala. | [🔗 Repositório](https://github.com/botcity-dev/botcity-framework-core-python) | Combina visão computacional de tela com chamadas para APIs web RESTful em um mesmo fluxo automatizado. |
| 10 | Zora | Plataforma de conformidade e auditoria de código aberto mantida pela Getup Cloud. | [🔗 Repositório](https://www.google.com/search?q=https://github.com/getup/zora-oss) | Utiliza a própria API do Kubernetes de forma intensiva para escanear componentes de clusters e garantir políticas de segurança. |
